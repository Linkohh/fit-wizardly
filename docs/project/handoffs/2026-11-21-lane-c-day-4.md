## What changed
- **`src/lib/analytics/track.ts` (new, contract #9):** `track(event, props?)`.
  - It does nothing, and loads nothing, unless `VITE_POSTHOG_KEY` is set **and** `hasAnalyticsConsent()` is true. It checks both on every call, so withdrawing consent stops sending straight away (Day 5 adds `opt_out_capturing()` on top).
  - `posthog-js` is loaded with a dynamic import on the first allowed event. Events sent while it loads wait in a queue capped at 50. If consent is withdrawn during the load, the queue is dropped and PostHog isn't started.
  - **Allow-list:** only `step`, `goal`, `days_per_week`, `exercise_count`, `duration_min`, `source` and `platform` are sent. Values must be strings (cut to 64 characters), finite numbers or booleans. Anything else is dropped. `platform` (`web`/`ios`/`android`, from `getNativePlatform()`) is added to every event.
  - **PostHog options:**
    - `api_host: https://eu.i.posthog.com` (EU).
    - Automatic collection is off: `autocapture`, `capture_pageview`, `capture_pageleave`, dead clicks, heatmaps, exceptions, performance and rageclick.
    - `persistence: 'localStorage'`.
    - Session recording, surveys and web experiments are off.
    - `disable_external_dependency_loading: true`, so PostHog never fetches remote scripts. Our CSP only allows scripts from `'self'`.
    - `advanced_disable_flags: true`: no `/flags` request.
    - `person_profiles: 'never'`: anonymous events only, and `identify()` is never called.
    - `mask_personal_data_properties: true`: campaign IDs such as gclid are masked.
  - **`before_send` (`scrubCapture`):**
    - Rechecks consent.
    - Strips the query string and hash from `$current_url`, `$pathname`, `$referrer` and the `$initial_*` URLs, in properties, `$set` and `$set_once`.
    - Replaces id-like path segments (UUIDs, long numbers, 20+ character tokens such as invite codes) with `:id`.
  - `track()` never throws.
- **`src/lib/analytics/usePageViews.ts` (new):** sends `track('$pageview')` on each `location.pathname` change. It's mounted in `App.tsx` and lives in its own file so it can be tested.
- **`src/lib/analytics/useAnalyticsConsent.ts` (new):** reads `fitwizard_analytics_consent` with `useSyncExternalStore`. It updates on `CONSENT_RESOLVED_EVENT`, and on `storage` events from other tabs.
