## What changed
- **Slider thumbs get their names.** New `src/components/a11y/LabelledSlider.tsx`. It looks the same as the shadcn `Slider` but puts `aria-label` / `aria-valuetext` on the Radix thumb (`role="slider"`), because the shadcn wrapper only takes them on the root. It also adds a 44 x 44 px invisible hit area (`after:-inset-3` on the 20 px thumb) and `min-h-[44px]` on the root. `src/components/ui/*` was not edited.
  - `ReadinessCheck.tsx`: the four sliders are now named "Sleep quality", "Energy level", "Muscle soreness" and "Stress level", with value text "N of 5".
  - `SetLogger.tsx`: the RIR/RPE thumb is named "Reps in reserve" or "Rate of perceived exertion", with value text like "3 - Moderate". Before, the root's name changed with every value.
  - `SculptSlider.tsx` (MCL): now uses `LabelledSlider`. The `querySelector` effect is gone, and the thumb has a 44 px hit area (DEBT-020) and value text like "60%".
- **Plate calculator button:** `aria-label="Open plate calculator"` and a `title`; the icon is `aria-hidden` (`src/components/tools/PlateCalculator.tsx`).
- **RIR is not colour-only.** The visible "N - Label" text (for example "3 - Moderate") was already next to the number after Day 4. This PR fixes its contrast: light theme now uses the -700 shades and dark theme keeps the -400 shades. The reps number colours also failed AA contrast in light theme (axe flagged them) and are fixed the same way.
- **`SetLogger.tsx` lines touched (for Lane B):** 5 (import), 116–120 (`getRIRColor` classes), 252–255 (reps input colour classes), 314 (`<Slider` → `<LabelledSlider`), 328–329 (`aria-label`/`aria-valuetext` → `thumbLabel`/`thumbValueText`). No strings were changed.
- **`WorkoutLogger.tsx`:** one line added at 356, `aria-label="Workout progress"` on the progress bar (axe: `aria-progressbar-name`, serious).
- **MCL touch targets (DEBT-020):** `LayerToggle.tsx` options get `min-h-[44px] min-w-[44px]` and centred content; they look the same. `SelectionSidebar.tsx` row buttons go from 36 px to 44 px.
- **DEBT-021, MCL theme:**
  - `src/features/mcl/hooks/useTheme.ts` copied the `theme` prop into state once, so app theme changes never reached the selector until a reload. In `system` mode it read the OS setting directly.
  - Now it follows the prop (and clears the selector's local toggle when the prop changes). In `system` mode it follows the `dark` class on `<html>` through `useSyncExternalStore` and a `MutationObserver`, so it matches `themeStore`.
  - `SelectionSidebar.tsx`: selected rows use semantic tokens (`text-foreground`, `text-muted-foreground`, `hover:bg-muted`, `text-destructive`) instead of `gray-200/300/400`, which were nearly invisible in light theme.
- **Reduced motion:** `src/App.tsx` wraps the tree in one `<MotionConfig reducedMotion="user">` (lines 1, 424–425 and 462). The inner tree was not re-indented, to keep the diff small for Lanes C, E and H. `src/App.home-route-regression.test.tsx` got a pass-through `MotionConfig` in its `framer-motion` mock (one line).
- **Tests:** `src/test/a11y-day5.test.tsx` (10 tests):
  - the thumb names and value text for the RIR slider, the four readiness sliders, the sculpt slider and the plate button
  - the RIR text label, including after a keyboard change
  - the hit-area classes on the slider thumbs, layer toggle and sidebar buttons
  - the semantic tokens in the sidebar
  - `useTheme` following an `<html>` class change and a prop change without a reload
