## What changed
- `src/lib/pdfExport.ts` (3.6b):
  - **"DAY 1: DAY 1:"**: new `stripLeadingDayPrefix()` drops a leading `Day N:` / `Day N -` / `Day N –` or a bare `Day N` from the day name. `formatPdfDayTitle()` builds the title, and prints just `DAY N` if nothing is left of the name.
  - **Headers wrapping mid-word**: the headers are now `EXERCISE · SETS · REPS · RIR · REST` (INTENSITY became RIR). Number columns have fixed widths (`PDF_TABLE_COLUMN_WIDTHS`: 18/22/22/24 mm) and horizontal cell padding is 2 mm instead of 4. They are sized for the longest translation (es/pt `DESCANSO`). Number-column headers are now centred over their values (they used to be left-aligned over centred numbers).
  - **Garbled emoji**: new `toPdfSafeText()` removes `\p{Extended_Pictographic}` plus the hidden parts of emoji sequences (ZWJ, variation selectors, keycap, skin tones, flag letters), then tidies the spacing. ©, ® and ™ are kept because WinAnsi has them. It is applied to the user name, goal note, day name, focus tags, warm-up, cool-down, exercise names and reps.
  - Headers, `FAILURE` and the `DAY N` label are translatable through `i18n.t()` with English fallbacks. They fall back to English if i18n hasn't initialised.
- `src/locales/{en,es,de,pt}.json`: new `pdfExport.*` namespace (headers ×5, `failure`, `dayLabel`), appended after `auth` as plain text. No JSON parser was used, and `git diff` shows only these 11 lines per file. All 4 locales are filled in, so `localeGaps.json` doesn't grow.
- `src/lib/pdfExport.test.ts`: 11 new tests:
  - prefix stripping, including `Daybreak Cardio` staying intact
  - no `DAY n: DAY` anywhere in the drawn text
  - the header set and column widths passed to autotable
  - **real jsPDF measurement**: every locale's headers fit their column at 8pt bold, and `FAILURE`/`FALLO`/`VERSAGEN`/`FALHA` fit at 9pt bold
  - helper cases for emoji stripping
  - no pictographs in any drawn text or table cell
- `vite.config.ts` `wgerProxyPlugin` (DEBT-074): a thrown upstream error now returns **502** `{ error: 'Upstream request failed' }`, the same as `api/proxy-wger.ts`. It used to return 500 with `err.message`.
