## What changed
- `src/stores/trainerStore.ts`: while `isFeatureEnabled('coach')` is false, `isTrainerMode` is always `false`.
  - The initial state was already `false`.
  - `sanitizeTrainerPersistedState` drops a persisted `isTrainerMode: true` on rehydrate.
  - `isTrainerAuthorized()` returns `false`, so `setTrainerMode(true)` and `toggleTrainerMode()` both leave the mode off. They also keep `wizardStore.selections.isTrainer` at `false`.
- `src/stores/onboardingStore.ts`: with coach off, `getStepsForRole` returns `['welcome', 'goals']` for every role. `setRole` and the persisted-state sanitiser force the role to `'user'`, so a stored `role: 'coach'` or `currentStep: 'role' | 'import'` falls back to `user` and `welcome`. `OnboardingFlow.tsx` needed no change: it already treats `goals` as the last step for a `user`.
- The coach toggle is hidden when coach is off:
  - `src/pages/Profile.tsx`: the "Coach Mode" row and the separator above it. Only the trainer block, one import and the `isTrainerEnabled` line changed. Lane B's language block is untouched.
  - `src/components/wizard/steps/GoalStep.tsx`: the whole trainer card ("I'm a trainer" switch plus coach notes).
- Coach entry points on `Index.tsx` (`TrainerDashboard`), `Plan.tsx` ("Save as Template") and `Analytics.tsx` (`WeeklyCoachSummaryCard`): `isTrainerEnabled` now also requires the coach flag. With the store change alone they would already stay hidden. The flag check guards against a stale or mocked store. **TrainerDashboard checked (carry-over):** it doesn't render with the flag off, even when `isTrainerMode` is `true`.
- `src/components/motivation/BadgeDisplay.tsx`: `BadgeGrid` leaves out `circle_*`, `team_player` and `social_butterfly` when circles is off, and `trainer_activated`, `first_client`, `clients_*` and `template_creator` when coach is off. The filter lives in the component; `achievementStore.ts` is untouched.
- `src/pages/UserGuide.tsx` (DEBT-047): with circles off, the "Social Circles" tab, its content and its "Go to Circles" link are hidden. The tab bar is hidden too, because only one tab would be left.
- `src/components/CommandPalette.tsx` (DEBT-050):
  - Removed "Achievements" (`/achievements` doesn't exist and there is no achievements page).
  - Removed "Settings" (`/settings` doesn't exist, and the settings are on `/profile`, which already has a "Profile" command just above it).
  - "Sign in" now opens the auth modal (`setShowAuthModal(true)`) instead of going to `/auth`.
  - "Documentation" now goes to `/guide` instead of opening `docs.fitwizardly.com`.
  - Removed the unused `Trophy` and `Settings` icon imports.
