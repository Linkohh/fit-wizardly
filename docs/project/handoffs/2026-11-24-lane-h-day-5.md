## What changed
- **New dependencies:** `@capacitor/status-bar` 8.0.4, `@capacitor/splash-screen` 8.0.2, `@capacitor/keyboard` 8.0.6, `@capacitor/share` 8.0.3. (`@capacitor/preferences` came in on Day 4; `@capacitor/filesystem` was already there.) `npx cap sync` registered them in `android/app/capacitor.build.gradle`, `android/capacitor.settings.gradle` and `ios/App/CapApp-SPM/Package.swift`.
- **`useStatusBarTheme()`** (`src/hooks/useStatusBarTheme.ts`, native code in `src/hooks/nativeChrome.ts`):
  - Follows `themeStore.resolvedTheme`: `Style.Dark` (light text) on the dark theme, `Style.Light` on the light theme.
  - Android: also `setBackgroundColor` with the `theme-color` values from `index.html` (`#1A0B2E` / `#F5F3FF`). On Android 15+ (we target SDK 36) the plugin doesn't support this and the app is edge to edge; the error is caught and the style still applies.
  - **Splash:** `capacitor.config.ts` now has `SplashScreen.launchAutoHide: false` (and `showSpinner: false`). The hook calls `SplashScreen.hide({ fadeOutDuration: 200 })` once `useStoresHydrated()` is true, once per app start. Hydration has its own 3 s safety valve, so a broken store can't keep the splash up.
  - Mounted with one line in `src/App.tsx`, next to `useAndroidBackButton()`.
- **`useKeyboard()`** (`src/hooks/useKeyboard.ts`): returns `{ isOpen, height }`.
  - iOS: `setResizeMode({ mode: Body })` and `setScroll({ isDisabled: false })`, also set in `capacitor.config.ts` (`Keyboard.resize: 'body'`, `resizeOnFullScreen: true`). Both are iOS-only APIs, so Android skips them.
  - On `keyboardDidShow` it scrolls the focused input to the middle of the screen (option `scrollFocusedIntoView`, default true).
  - Not mounted anywhere yet: see "To Lane D".
- **`useShare()`** (`src/hooks/useShare.ts`): `share(data)` resolves `true` if the share went through and `false` if it's unavailable, cancelled or failed; it never throws.
  - Native: `@capacitor/share`. Files are written to the cache folder (`share/<name>`) with `@capacitor/filesystem` and passed as `file://` URLs.
  - Web: `navigator.share`, with `navigator.canShare` required for files, as before.
  - Also returns `canShare(data?)` so callers can choose the clipboard fallback without also copying after a cancel.
- **`WorkoutSummary.tsx` share block** now uses `useShare()`. The behaviour on the web is the same: image card if the browser can share files, otherwise the text share, otherwise copy to the clipboard with the "Stats copied" toast. On native the card now goes through the native share sheet.
- **Lane E's `appStateChange` sync trigger** (`src/lib/sync/triggers.ts`) isn't touched. None of the new plugins add `@capacitor/app` listeners, so the trigger keeps working; its tests pass unchanged.
- **Tests:** `useStatusBarTheme.test.tsx` (web no-op; iOS style follows theme changes; Android colour, including Android 15+ rejecting it; splash hides only after hydration, only once), `useKeyboard.test.tsx` (web no-op; iOS setup and open/close state; Android skips iOS calls; focused input scrolled into view; listeners removed on unmount), `useShare.test.tsx` (web share, cancel, no Web Share API, files refused by `canShare`; native share, files written to cache, cancel, file write failure).
